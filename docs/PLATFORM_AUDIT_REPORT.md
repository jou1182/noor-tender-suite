## 🔧 المشاكل المكتشفة والمُصلحة (جلسة اليوم)

### 🔴 حرجة — أُصلحت
1. **Path Traversal في حذف المستندات** (`documents.py`)
   - المشكلة: `startswith(upload_root)` كانت تسمح بحذف ملفات مجلدات مجاورة مثل `uploads_evil/` أو `uploads-backup/`
   - الإصلاح: `os.path.realpath()` + فحص بحدود `os.sep` — مُختبر الآن بثلاث سيناريوهات هجومية ✓

2. **Filename Injection في رفع المنافسات** (`main.py audits/trigger`)
   - المشكلة: `rfp.filename` من المستخدم كان يُستخدم مباشرة في مسار الحفظ — هجوم `../../` ممكن
   - الإصلاح: `os.path.basename()` على كل أسماء الملفات (RFP + Schedule) ✓

3. **تلف توقيع دالة المصادقة** (`main.py`)
   - المشكلة: `str *** Header` (حرف فاسد بدل `=`) — كانت ستكسر الإقلاع في أي بيئة نظيفة
   - الإصلاح: صحّح التوقيع + وُحّد قراءة JWT secret من مصدر واحد (`app/core/security.py`) بدل تكراره hardcoded ✓

### 🟠 متوسطة — أُصلحت
4. **CORS مفتوح بالكامل** (`allow_origins=["*"]` مع credentials)
   - الإصلاح: قائمة بيضاء عبر متغير البيئة `ALLOWED_ORIGINS` (افتراضي: localhost:3000 فقط) ✓

5. **استيرادات ميتة + non-null assertion خطرة** (`page.tsx`)
   - الإصلاح: حذف `TENANTS, demoSystemHealth, demoLlmMetrics` الميتة + استبدال `redTeamData!` بفحص آمن ✓

## ⚠️ ملاحظات مسجلة — تتطلب قراراً مستقبلياً (ليست أعطال)

### أمان (للنشر الإنتاجي):
| البند | الوضع | التوصية |
|---|---|---|
| JWT Secret | قيمة افتراضية dev معروفة في الكود | قبل أي نشر: `SECRET_KEY` عشوائي 64+ حرف في `.env` — الكود يقرؤه من env بالفعل |
| نقاط API بلا مصادقة | tenders/documents/providers/agents مفتوحة على الشبكة المحلية | مقبول للاستخدام الفردي المحلي؛ قبل النشر السحابي: طبقة auth موحدة (middleware) |
| Rate limiting | موجود في tenant_manager لكن غير مربوط بالمسارات | تفعيله عند النشر متعدد المستخدمين |
| HTTPS | غير مهيأ محلياً | يأتي تلقائياً مع نشر خلف nginx/سحابة |

### دين functional (ديون تقنية مرتبة بالأولوية):
1. **صفحة `/dashboard` (Portfolio)** — ما زالت بيانات demo ثابتة — **الأولوية القادمة**: ربطها بـ`GET /api/v1/tenders` (البنية جاهزة)
2. **صفحة workspace للمشروع** — demo VE cards/method statements — نفس المعالجة
3. **Pagination** لقوائم المنافسات/المستندات (حالياً تعود كاملة — مقبول حتى مئات السجلات)
4. **RAG keyword fallback** يحمّل كل chunks بالذاكرة — تحسينه بـLIMIT عند تجاوز 10k chunk

### ملاحظة بيئية (ليست خطأ كود):
- `next build` المحلي يفشل عشوائياً بسبب مضاد الفيروسات (EISDIR readlink) — **البناء داخل Docker يعمل دائماً** وهو مسار النشر المعتمد
